# Notes

## Sub-features
About dialog: what this imagined island is and is not, gesture summary, fact sources (UNESCO, Smithsonian, Wikipedia).

## How to get to it (user POV)
The `i` orb, top right. Escape or the close button leaves.

## Driving it with Playwright
`#about` opens the `dialog`; Escape closes; assert visibility flips.

## Gotchas
Links open in a new tab with noopener. Facts must stay humble and sourced - recheck them if copy changes.
